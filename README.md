## 🚀 Getting Started

### 1. Install Arduino IDE

Download and install the latest Arduino IDE:

https://www.arduino.cc/en/software

### 2. Install ESP32 Board Support

Add the ESP32 board package to Arduino IDE and select the appropriate ESP32 board.

The official Arduino-ESP32 project supports the ESP32 family and provides documentation for installation and development.

### 3. Clone the Repository

```bash
git clone https://github.com/faiyaz029/ESP32.git
cd ESP32
```

### 4. Open a Project

Navigate to the required project folder and open the `.ino` file in Arduino IDE.

### 5. Configure Credentials

Some projects require credentials such as:

```cpp
const char* WIFI_SSID = "YOUR_WIFI_NAME";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";
```

Other projects may require:

* Telegram Bot Token
* Chat ID
* Google Apps Script URL
* MQTT broker information
* API keys

**Do not commit private credentials or API keys to GitHub.**

### 6. Upload

Connect the ESP32 to your computer, select:

* **Board:** Your ESP32 board
* **Port:** Connected ESP32 port
* **Baud Rate:** Project dependent

Then compile and upload the firmware.

## 🔐 Security

Some projects in this repository are intended for **educational and experimental purposes**.

When working with Wi-Fi or network-related projects, only test on networks and devices that you own or have explicit permission to test.

Never upload:

```text
Wi-Fi passwords
API keys
Telegram bot tokens
Private credentials
Authentication tokens
```

Use placeholders or environment/configuration files instead.
